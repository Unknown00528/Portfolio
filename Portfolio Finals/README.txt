JOHN VENSON CARAIG - ACADEMIC PORTFOLIO
=======================================

Files:
- index.html: main portfolio and lecture modules
- instructor.html: separate instructor profile page
- style.css: responsive design
- script.js: interactive lecture table of contents and expandable notes
- assets/profile.jpg: student profile image
- assets/instructor.jpg: add the instructor's real photo here (optional placeholder appears until added)

Built with HTML, CSS, Bootstrap 5, Bootstrap Icons, and vanilla JavaScript.
Static website; suitable for Netlify. No build command required.

To deploy: upload this folder to a GitHub repository and connect it to Netlify,
or use Netlify Drop with the extracted folder.
